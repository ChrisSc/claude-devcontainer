# Agent Toolkit for AWS — default skill set (the `aws-core` catalog category).
#
# Installed into ~/.claude/skills by init-aws-toolkit.sh at boot. Format is
# `<skill-name> <version>`, one per line; `#` comments and blank lines ignored.
#
# PINNED deliberately (org supply-chain standard): the catalog's `add-skill`
# defaults to *latest*, so an unpinned list would silently change what guidance
# Claude loads on any given boot. Bump versions here as a reviewed diff.
#
# init-aws-toolkit.sh keys its "already seeded" stamp on the SHA-256 of this
# file, so editing it (adding, removing, or re-pinning a skill) is what triggers
# a reconcile on the next boot. Skills removed from this list are NOT uninstalled
# — drop them with `aws agent-toolkit remove-skill --skill-name <n> --agent claude-code`.
#
# Regenerate the whole list at the current catalog versions with:
#   aws agent-toolkit list-available-skills --category-filter aws-core \
#     --region us-east-1 --output json | jq -r '.skills[]|"\(.name) \(.skillVersion)"'
#
# The full catalog is ~101 skills; browse the rest with
# `aws agent-toolkit list-available-skills --region us-east-1`.
